# Pitch slides

Six-slide support deck for the 30-second trailer and 2:30 live G60 / US product story in `notes/pitch-plan.md`. The middle slides are visual backup for the live clicks. The opening and close can bookend the demo without turning the three-minute pitch into a slide walkthrough.

## Files

- `output/pitch-reference-template.pptx`: editable slide template using the visual language of the [Invertix security page](https://www.invertix.ai/security): copper grain, editorial headings, pale square cards, thin line icons, and black sections.
- `output/pitch-bmw-dashboard-animated.pptx`: editable BMW dashboard adaptation with Barlow and IBM Plex Mono font assignments, the dashboard roundel, the dashboard palette, and click-driven fade transitions.
- `output/pitch-bmw-motion.html`: self-contained browser presentation with the same six slides and staged motion. The font files and car image are embedded, so it works offline.

## Presenting

Open the HTML file in a browser for the full motion treatment. Use Right/Left, Space, Page Up/Page Down, Home/End, or the hover controls to navigate. Press `F` for fullscreen and `R` to replay the current slide. The deck advances only when the presenter chooses.

The PowerPoint version uses slide fades. Text, card backgrounds, and rules remain editable. For the intended PowerPoint typography, install Barlow and IBM Plex Mono on the presentation machine; the HTML version embeds both.

Slide 5 describes a **simulated update** because the source feedback has no dates. Keep that label visible. Before the pitch, verify the charging update path against the prepared demo database as required by the pitch plan.
